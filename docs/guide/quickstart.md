# Quickstart & Keyboard Controls

Vectrace provides a streamlined experience using mouse gestures, floating glassmorphic toolbar buttons, and global hotkeys.

## Keyboard Controls Reference

| Shortcut | Function |
| :--- | :--- |
| `Ctrl + Alt + A` | **Global Daemon Shortcut**: Toggle Passthrough / Active Mode |
| `Space` | Toggle Click-Through Mode |
| `Ctrl + Shift + S` / `Ctrl + C` | Activate Crop Selection Tool |
| `S` | Capture Full Screen & Copy to Clipboard |
| `U` | Undo last drawn stroke |
| `R` | Redo last undone stroke |
| `C` | Clear canvas drawings |
| `B` | Cycle Background Mode (Clear ➔ Blackboard ➔ Whiteboard) |
| `ESC` | Cancel current tool / Exit application |
