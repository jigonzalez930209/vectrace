# Crop & Snapshot Engine

Vectrace features a high-performance region cropping tool that captures desktop content and annotations seamlessly.

![Crop Selection](/images/crop-selection.png)

## Snapshot Features
- **Full Screen Snapshot (`S`)**: Instantly captures desktop background and all vector strokes, saving to `~/Pictures` and copying to clipboard.
- **Crop Region (`Ctrl+Shift+S`)**: Interactive handles for selecting, moving, and resizing region snapshots with instant pixel dimensions.
