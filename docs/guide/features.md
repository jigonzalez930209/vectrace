# Features & Tools Guide

Vectrace includes a versatile suite of vector annotation tools designed for live presentations and screencasts.

## Drawing & Geometric Tools

- **Freehand Pen**: Smooth spline drawing with pressure simulation.
- **Highlighter**: Semi-transparent yellow marker for emphasizing text and code.
- **Line & Arrow**: Draw straight vectors and directional arrows.
- **Rectangle & Oval**: Quick geometric shapes for bounding UI elements.
- **Text Tool**: Place crisp vector labels anywhere on screen.
